## المشكلة

حسابك فعلاً مسجّل كأدمن في قاعدة البيانات (`+967782566694` موجود في جدول `app_admins`)، لكن صفحة `/auth` بعد التحقق من رمز OTP لا تتحقق من صلاحية الأدمن — فقط تتحقق من الدور (عميل/تاجر) وترسلك لـ `/choose-role` أو `/home`، فيبدو لك أنك عميل عادي.

التوجيه الصحيح للأدمن موجود فقط في `src/routes/index.tsx`، لكنه لا يُستدعى لأن `/auth` يقفز مباشرة لـ `/home`.

## الحل

تعديل `src/routes/auth.tsx` فقط — إضافة فحص `isCurrentUserAdmin()` قبل فحص الدور، بحيث تذهب مباشرة إلى `/admin` بعد تسجيل الدخول.

```ts
// بعد signInOrSignUpWithPhone
if (await isCurrentUserAdmin()) {
  navigate({ to: "/admin" });
  return;
}
const role = await getUserRole(user.id);
// ... باقي المنطق كما هو
```

## ملاحظة للاختبار

- سجّل خروج من التطبيق (من شاشة البروفايل) ثم أعد الدخول برقم `782566694` — ستذهب مباشرة للوحة الإدارة.
- إذا اخترت سابقاً دور "عميل" أو "تاجر"، هذا لا يمنع لوحة الإدارة — صلاحية الأدمن مستقلة وتظهر دائماً.
