# خطة تطوير لوحة الإدارة الاحترافية

تنفيذ على **4 مراحل متتالية**، كل مرحلة منتج قابل للاستخدام لوحدها.

---

## المرحلة 1 — مركز التحليلات والتقارير (Analytics Hub)

شاشة `/admin/analytics` جديدة + توسعة `/admin/index`.

### 1.1 محرك التقارير المشترك (مكوّن `ReportFilters`)
فلاتر علوية تنطبق على كل التقارير:
- نطاق تاريخ (اليوم / 7 أيام / 30 يوم / هذا الشهر / مخصص)
- المدينة / المتجر / الفئة / القناة (أونلاين أو محل) / طريقة الدفع / الحالة
- زر **تصدير Excel** وزر **تصدير PDF** ظاهران دائماً

### 1.2 لوحة المبيعات والإيرادات والعمولات
- KPIs: إجمالي المبيعات، عدد الطلبات، متوسط قيمة الطلب، إجمالي العمولات، صافي مستحقات التجار
- رسم خطي: المبيعات اليومية
- رسم أعمدة: المبيعات حسب المتجر (Top 10)
- رسم دائري: حسب طريقة الدفع / حسب القناة
- جدول تفصيلي قابل للتصدير

### 1.3 تحليل العملاء
- KPIs: عملاء جدد، نشطون (آخر 30 يوم)، خاملون، متوسط الإنفاق، LTV تقريبي
- Top 20 عميل إنفاقاً (مع رقم الجوال والمدينة)
- توزيع العملاء حسب المدينة
- معدل التكرار (طلب واحد / 2-5 / 6+)

### 1.4 تحليل التجار والمنتجات
- لكل متجر: عدد الطلبات، الإيراد، التقييم، نسبة الإلغاء، نسبة المرتجعات، زمن قبول الطلب
- Top منتجات مبيعاً (كمية + إيراد)
- منتجات بطيئة الحركة (لا حركة آخر 30 يوم)
- منتجات نفد مخزونها
- أكثر المنتجات إرجاعاً مع الأسباب

### 1.5 تحليل جغرافي وتشغيلي
- خريطة Google Maps تفاعلية لليمن:
  - نقاط المتاجر (لون حسب الحالة)
  - Heatmap لمواقع الطلبات
  - فلتر حسب الفترة
- ذرى الطلبات بالساعة (Heatmap يوم × ساعة)
- متوسط زمن قبول الطلب وزمن التوصيل لكل متجر/مدينة

## المرحلة 2 — صلاحيات التحكم التشغيلي

### 2.1 إدارة المنتجات والكتالوج المركزي
- `/admin/products` — قائمة بكل منتجات النظام مع فلتر متجر/فئة/حالة:
  - تعديل سعر / إيقاف / حذف أي منتج
  - زر "حجب من العرض للعملاء" (soft hide)
- `/admin/catalog` — إدارة الكتالوج العام و`catalog_categories`:
  - إضافة/تعديل/دمج فئات وأصناف عامة
  - اعتماد منتج تاجر ليصبح ضمن الكتالوج العام

### 2.2 إدارة الطلبات (توسعة `/admin/orders`)
- زر **إلغاء طلب** + سبب
- زر **تعديل الحالة يدوياً** (حالات استثنائية)
- زر **فرض استرداد** (يُضاف للمحفظة تلقائياً)
- زر **إعادة تعيين لمتجر آخر** (للطلبات المعلّقة)

### 2.3 إدارة العملاء (توسعة `/admin/users`)
- بطاقة عميل: ملخص نشاطه، طلباته، رصيد محفظته، أرصدة الأجل
- **حظر / تعليق مؤقت** (يمنع تسجيل الدخول)
- **تعديل سقف الأجل**
- **إشعار فردي** لمستخدم بعينه
- حذف الحساب (مع تأكيد)

## المرحلة 3 — التسويات المالية والحوكمة

### 3.1 تسويات التجار `/admin/settlements`
- لكل متجر، لفترة محددة:
  - إجمالي مبيعات أونلاين، عمولة المنصة، صافي مستحق للتاجر
  - مدفوع مقابل غير مدفوع
- زر **تأكيد دفعة تسوية** (ينشئ سجل `settlements` + ملاحظة)
- كشف حساب PDF بشعار التطبيق
- تصدير Excel بكل التفاصيل

### 3.2 إعدادات مالية متقدمة (توسعة `/admin/settings`)
- جدول العمولات حسب المدينة / الفئة (override للنسبة الافتراضية)
- رسوم شحن المحفظة لكل بوابة
- حدود السحب/الإيداع

### 3.3 أدوار فرعية وسجل تدقيق
- نوع أدمن: `super_admin` / `finance` / `operations` / `support`
- مصفوفة صلاحيات لكل دور (قراءة/كتابة على كل قسم)
- جدول `admin_audit_log`: من فعل ماذا، متى، على أي سجل، القيم قبل/بعد
- شاشة `/admin/audit` لاستعراضه مع فلاتر

## المرحلة 4 — التقارير المجدولة والأتمتة

### 4.1 تقارير مجدولة
- شاشة `/admin/scheduled-reports`:
  - تعريف تقرير (نوع + فلاتر + تنسيق)
  - جدولة (يومي / أسبوعي / شهري)
  - وجهة الإرسال (إشعار داخلي / واتساب عبر رقم الدعم)
- مهمة pg_cron + TanStack server route تولّد التقرير وتُرسله

### 4.2 تنبيهات ذكية للأدمن
- متجر لم يقبل طلب خلال X دقيقة
- ارتفاع غير معتاد بالإلغاءات لمتجر
- منتج نفد من +10 متاجر

## التفاصيل التقنية

### قاعدة البيانات (migrations جديدة)
- `admin_role` enum + عمود في `app_admins`
- `admin_permissions` (دور × قسم × مستوى صلاحية)
- `admin_audit_log` (admin_id, action, entity_type, entity_id, before jsonb, after jsonb, created_at)
- `settlements` (store_id, period_start, period_end, gross, commission, net, paid_at, paid_by, note)
- `scheduled_reports` (type, filters jsonb, schedule cron, destination, last_run_at)
- توسعة `profiles` بعمود `status` (active/suspended/banned) + RPC `admin_set_user_status`
- RPCs جديدة كلها بـ `is_admin()` + تسجيل تلقائي في `admin_audit_log`:
  - `admin_cancel_order`, `admin_refund_order`, `admin_set_user_status`, `admin_set_user_credit_limit`, `admin_set_product_status`, `admin_create_settlement`, `admin_send_user_notification`

### الواجهة الأمامية
- مكتبات: `recharts` (موجودة)، `xlsx` للتصدير Excel، `jspdf` + `jspdf-autotable` للـ PDF
- مكوّن مشترك `<ReportShell>` + `<ReportFilters>` + `<ExportButtons>`
- بطاقة `<KpiCard>` موحّدة
- إضافة بنود إلى `AdminShell` التنقّل: تحليلات، منتجات، كتالوج، تسويات، تدقيق، تقارير مجدولة (سيُقسم إلى مجموعتين بسبب العدد)
- خريطة `<AdminYemenMap>` تستخدم `GOOGLE_MAPS_BROWSER_KEY` الموجود

### الأمن
- كل RPC إداري يبدأ بـ `IF NOT public.is_admin() THEN RAISE EXCEPTION 'forbidden'`
- كل RPC حسّاس يسجّل تلقائياً في `admin_audit_log`
- صلاحيات الأدوار الفرعية تُفحص داخل RPC قبل الإجراء
